# 0003: MVP Scope Boundaries and Deferred Features

We decided to keep the MVP strictly focused on the complete social birding loop: expedition scheduling, carpool seat claiming, multi-channel messaging, interactive mapping, and field sighting logging with shared checklists. We explicitly deferred real-money payment processing, native app store packaging, and automated ML bird call/photo recognition to Phase 2. This prevents third-party payment and model training dependencies from blocking a fast, highly functional release.
