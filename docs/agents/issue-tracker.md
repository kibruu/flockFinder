# Issue Tracker: GitHub Projects & Issues

Issues and specs for this repo live as GitHub issues integrated with GitHub Projects.

- **Repository**: [https://github.com/kibruu/flockFinder](https://github.com/kibruu/flockFinder)
- **Project Board**: [GitHub Project #3](https://github.com/users/kibruu/projects/3)
- **Tooling**: Uses the `gh` CLI for all issue management and querying.

## Conventions

- **Create an issue**: `gh issue create --repo kibruu/flockFinder --title "..." --body "..."`
- **Read an issue**: `gh issue view <number> --repo kibruu/flockFinder --comments`
- **List issues**: `gh issue list --repo kibruu/flockFinder --state open`
- **Add to Project Board**: `gh project item-add 3 --owner kibruu --url <issue-url>`
